# 🪶 鹈鹕骑士 · Pelican Cyclist 3D

一只戴着头盔、系着围巾的鹈鹕,骑着自行车巡航在无尽乡间公路上。
单文件 Three.js 页面,零构建、零外部资源(仅从 CDN 加载 three.js)。

**在线访问(CDN)**: <https://cdn.jsdelivr.net/gh/JairHan/pelican-bike-3d@main/index.html>

## 亮点

- **纯程序化建模**:鹈鹕(喙、喉囊、羽冠、头盔、围巾)、自行车(车架、辐条、牙盘、链条、前筐带鱼)、行道树、云、丘陵,全部用几何体拼装
- **双骨反向动力学(IK)**:两条腿实时解析求解膝盖位置,脚掌精确跟随踏板做圆周运动,踏频与车轮转速按齿比联动
- **卡通着色**:MeshToonMaterial + 4 阶色阶,PCFSoft 软阴影,着色器渐变天穹
- **昼夜切换**:天空/雾/光照/星空连续过渡,夜晚自动亮起车头灯
- **4 种机位**:环绕(轨道控制)、跟拍、侧面、电影运镜
- **Web Audio 合成车铃**:纯正弦波分音合成 "叮铃" 声,无需音频文件
- **交互**:速度滑杆(0–45 km/h)、暂停、快捷键、点击鹈鹕有惊喜
- **性能仪表**:实时速度/踏频/里程/FPS

## 快捷键

`Space` 暂停 · `B` 铃铛 · `N` 昼夜 · `1-4` 切换机位

## 运行

直接用浏览器打开 `index.html`,或:

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
